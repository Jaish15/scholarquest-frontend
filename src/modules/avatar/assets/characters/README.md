## Folder structure
```
characters/
├── humans/              # 12 characters, no outline (default, cleaner for UI)
│   └── outline/         # same 12, with outline (use for battle/map sprites on busy bg)
├── villagers/            # 10 characters, no outline
│   └── outline/
└── villagers2/
    ├── original/         # 10 characters, brown/earth tones — matches dashboard palette
    │   └── outline/
    └── blue/             # same 10, blue variant — could be used for a "night mode" or rival faction
        └── outline/
```

## Suggested ScholarQuest role mapping

| Character (pack)         | Suggested ScholarQuest use                          |
|---------------------------|------------------------------------------------------|
| MiniPeasant, MiniWorker    | Base/starter avatar options                          |
| MiniVillagerMan/Woman      | Default customizable avatar body                     |
| MiniNobleMan/Woman          | High-level / prestige avatar unlock                  |
| MiniKingMan, MiniQueen      | Top leaderboard rank avatar (e.g. Level 20+)          |
| MiniPrinceMan, MiniPrincess | Mid-tier rank unlock                                  |
| MiniMage, MiniArchMage      | Focus Points (Honey) milestone unlock — "Study Mage"  |
| MiniArcherMan, MiniCrossBowMan | Habit Streak (Bricks) milestone unlock             |
| MiniShieldMan, MiniSwordMan | Consistency streak badge avatars                      |
| MiniMerchant, MiniSuspiciousMerchant | Shop NPC (Honesty Gold Shop)                 |
| MiniBlacksmith              | Crafting/customization NPC                           |
| MiniHunter, MiniLumberjack, MiniMiner, MiniGatherer | "Resource" mini-games or daily quest NPCs |
| MiniNun                     | Wellness/break-reminder NPC                          |
| MiniThief, MiniGraveDigger  | Optional "distraction" or comic-relief event NPCs    |
| MiniOldMan/Woman            | Mentor/tutorial guide NPC                            |

Use the **villagers2/original** (brown/earth) set as your primary palette match for
the dashboard's amber-and-green theme; **blue** variant works well as an alternate
faction, night-mode, or "focus mode" reskin without needing new art.
